# /exp-run

> Выполнение эксперимента, запланированного в wiki/experiments/.
> **Независимо от режима работы, перед подготовкой экспериментальных кодов и их развёртыванием для эксплуатации необходимо получить подтверждение от пользователей. Пользователи должны вручную проверить соответствующую информацию, включая коды и экспериментальные конфигурации (пути к наборам данных, выбор параметров интерфейса, конфигурация API и т.д.). Эксплуатация может быть запущена только после подтверждения; в противном случае вносятся исправления до получения согласия пользователей на выполнение.**
> **Три режима запуска** для различных сценариев:
> - **По умолчанию (развёртывание)**: только фазы 1-2 — развёртывание и немедленный возврат. Лучше для экспериментов, занимающих часы или дни.
> - **`--collect`**: только фазы 3-4 — проверка завершения развёрнутого эксперимента; сбор результатов (`--check` — псевдоним).
> - **`--full`**: все 4 фазы от начала до конца. Лучше для коротких локальных экспериментов.
>
> Рекомендуемый процесс: `/exp-run <slug>` для развёртывания → `/exp-status` для мониторинга → `/exp-run <slug> --collect` для сбора.

## Входы

- `experiment`: slug из wiki/experiments/
- `--review` (опционально): включение проверки кода Review LLM
- `--collect` (опционально): режим сбора
- `--full` (опционально): полный режим
- `--env local|remote` (опционально, по умолчанию `local`): среда развёртывания

## Выходы

- **Режим развёртывания**: экспериментальный код, обновлённый статус, ОТЧЁТ_О_РАЗВЁРТЫВАНИИ
- **Режим сбора**: обновлённый статус/результаты, ОТЧЁТ_О_ЗАПУСКЕ
- **Полный режим**: все выходы развёртывания и сбора

## Взаимодействие с Wiki

### Чтение
- `wiki/experiments/{slug}.md` — конфигурация эксперимента
- `wiki/ideas/{linked-idea}.md` — подход связанной идеи
- `wiki/papers/*.md` — детали методов связанных статей
- `wiki/experiments/*.md` — другие эксперименты над той же идеей

### Запись
- `experiments/code/{slug}/` — директория кода эксперимента
- `wiki/experiments/{slug}.md` — обновление статуса, результатов
- `wiki/log.md` — добавление в журнал

### Создаваемые графовые рёбра
- **Нет**. Рёбра tested_by создаются /exp-design.

## Рабочий процесс

**Предусловие**: убедитесь, что рабочая директория — корень проекта wiki.

---

### Режим развёртывания (по умолчанию, status == planned)

**Фаза 1: Подготовка**

1. Чтение страницы эксперимента
2. Загрузка контекста реализации
3. Проверка набора данных и конфигураций
4. Написание экспериментального кода в `experiments/code/{slug}/`
5. Проверка работоспособности (валидация в малом масштабе)

**Контрольная точка: ручная проверка пользователями**

**Фаза 2: Развёртывание**

#### Локальный режим
1. Проверка GPU через `nvidia-smi`
2. Запуск через `screen -dmS exp-{slug} ...`
3. Обновление статуса в wiki
4. Оценка времени выполнения

#### Удалённый режим
1. Проверка доступности через `python3 tools/remote.py status`
2. Поиск свободного GPU
3. Синхронизация кода
4. Установка зависимостей
5. Запуск удалённого эксперимента
6. Обновление frontmatter

---

### Режим сбора (--collect, status == running)

**Фаза 3: Мониторинг / проверка статуса**

1. Чтение информации о развёртывании
2. Проверка статуса процесса (screen/SSH)
3. При работающем эксперименте: получение логов, обнаружение аномалий
4. При завершённом эксперименте: переход к фазе 4

**Фаза 4: Сбор результатов**

1. Получение удалённых результатов (при remote)
2. Проверка наличия файлов результатов
3. Парсинг результатов (среднее ± стд)
4. Обновление страницы эксперимента
5. Добавление в журнал
6. Вывод ОТЧЁТА_О_ЗАПУСКЕ

---

### Полный режим (--full, status == planned)

Последовательное выполнение всех 4 фаз.

## Ограничения

- **Режим развёртывания принимает только planned эксперименты**
- **Режим сбора принимает только running эксперименты**
- **Режим сбора: не записывайте в wiki при alive**
- **Код хранится в experiments/code/{slug}/**
- **Не обновляйте статус связанной идеи**
- **Проверка работоспособности обязательна**
- **Результаты должны быть сохранены**
- **Графовые рёбра здесь не создаются**
- **Попытки автоматического исправления ограничены 1**

## Обработка ошибок

- **Эксперимент не найден**
- **Режим развёртывания, но status == running**
- **Режим сбора, но status == completed**
- **GPU недоступен**
- **Review LLM недоступен** (--review)
- **Проверка работоспособности не прошла**
- **Удалённое подключение не удалось**
- **Файлы результатов отсутствуют**
- **Эксперимент упал** (traceback)
- **Тайм-аут --full**
