# /paper-compile

> Компиляция LaTeX-статьи в PDF, автоисправление типичных ошибок и проверка требований к подаче.
> Вход: директория paper/, сгенерированная /paper-draft. Запуск компиляции latexmk,
> парсинг ошибок и попытка автоисправления (отсутствующие пакеты, неопределённые ссылки, пути к фигурам).
> Проверка лимита страниц, соответствия анонимности, встраивания шрифтов и наличия маркеров [UNCONFIRMED].
> Генерация чеклиста подачи.

## Входы

- `paper_dir` (опционально, по умолчанию `paper/`): директория проекта LaTeX, содержащая `main.tex`
- `--fix` (опционально): включение режима автоисправления (автоматическая установка отсутствующих пакетов, исправление путей)
- `--checklist` (опционально): генерация подробного чеклиста подачи (только проверка, без компиляции)

## Выходы

- `paper/main.pdf` — скомпилированный PDF
- **COMPILE_REPORT** (выводится в терминал) — статус компиляции, результаты проверок, чеклист подачи
- При `--fix`: изменённые .tex файлы (автоисправленные)

## Рабочий процесс

**Предусловие**: убедитесь, что `paper/main.tex` существует. Убедитесь, что `latexmk` установлен (`which latexmk`).

### Шаг 1: Компиляция

1. **Первая компиляция**:
   ```bash
   cd paper/ && latexmk -pdf -interaction=nonstopmode main.tex 2>&1
   ```

2. **Парсинг вывода компиляции**:
   - Сбор всех ошибок (`! ...`)
   - Сбор всех предупреждений (`Warning:` / `Overfull` / `Underfull`)
   - Классификация:
     - **Отсутствующий пакет**: `! LaTeX Error: File 'xxx.sty' not found`
     - **Неопределённая ссылка**: `LaTeX Warning: Reference 'xxx' on page N undefined`
     - **Неопределённая цитата**: `LaTeX Warning: Citation 'xxx' on page N undefined`
     - **Отсутствующая фигура**: `! LaTeX Error: File 'figures/xxx' not found`
     - **Ошибка синтаксиса**: другие ошибки, начинающиеся с `!`
     - **Overfull/Underfull**: предупреждения о верстке (неблокирующие)

3. **Если компиляция успешна** (main.pdf создан): переходите к шагу 3
4. **Если компиляция не удалась**: переходите к шагу 2

### Шаг 2: Автоисправление

Если `--fix` включён, попробуйте автоисправить каждый тип ошибки:

**2a. Отсутствующий пакет**:
```bash
# проверьте, доступен ли пакет через TeX Live
tlmgr info {package-name} 2>/dev/null
# если доступен и пользователь подтверждает:
tlmgr install {package-name}
```
Если не доступен: закомментируйте строку `\usepackage{xxx}` и аннотируйте `% TODO: install package {xxx}`

**2b. Неопределённая ссылка/цитата**:
- Неопределённая ссылка: проверьте, существует ли соответствующий `\label{}`; если нет, добавьте заполнительный label
- Неопределённая цитата: проверьте, содержит ли `references.bib` ключ
  - Если нет: попробуйте сопоставить из статей wiki и добавьте запись [UNCONFIRMED]
  - Если есть, но bibtex не был запущен: перезапустите `latexmk` (обычно обрабатывает это автоматически)

**2c. Отсутствующая фигура**:
- Проверьте, содержит ли `paper/figures/` файл с другим расширением (.pdf vs .png vs .eps)
- Если найден: исправьте путь `\includegraphics`
- Если не найден: замените заполнителем `\missingfigure{xxx}` (требуется пакет `todonotes`)

**2d. Ошибка синттаксиса**:
- Типичные исправления: незакрытые `{}`, несовпадающие `\begin{}`/`\end{}`, недопустимые символы
- Попробуйте найти номер строки ошибки; предложите конкретные исправления
- Если автоисправление невозможно: сообщите расположение ошибки и предложения

**Повторная компиляция после исправлений** (до 3 циклов исправление-компиляция):
```bash
cd paper/ && latexmk -pdf -interaction=nonstopmode main.tex 2>&1
```

### Шаг 3: Проверки

После успешной компиляции выполните следующие проверки:

**3a. Проверка количества страниц**:
```bash
# получение количества страниц PDF
python3 -c "
import subprocess
result = subprocess.run(['pdfinfo', 'paper/main.pdf'], capture_output=True, text=True)
for line in result.stdout.splitlines():
    if line.startswith('Pages:'):
        print(line.split(':')[1].strip())
"
```
Сравните с лимитом страниц площадки (из PAPER_PLAN или таблицы площадок в academic-writing.md).
- Превышает лимит: сообщите количество страниц сверх лимита; предложите сжать или перенести содержимое в приложение
- Ниже лимита: сообщите оставшееся пространство; предложите добавить содержимое

**3b. Проверка анонимности**:
Сканирование всех .tex файлов:
- Поиск имён авторов (если `\author{}` не пуст → предупреждение)
- Поиск названий учреждений (университет, институт → предупреждение)
- Поиск ссылок GitHub/GitLab (могут раскрыть личность → предупреждение)
- Поиск "our previous work" / "we previously" → следует использовать ссылку от третьего лица
- Поиск `\thanks{}` / `\acknowledgments` → удалить для анонимной подачи

**3c. Проверка маркеров [UNCONFIRMED]**:
```bash
# сканирование references.bib и всех .tex файлов
grep -rn "VERIFY" paper/
```
- Если маркеры [UNCONFIRMED] существуют: перечислите каждый; пометьте как **блокатор подачи**
- Согласно citation-verification.md: [UNCONFIRMED] — жёсткий блокатор подачи

**3d. Проверка встраивания шрифтов**:
```bash
pdffonts paper/main.pdf
```
- Проверьте столбец "emb": все шрифты должны быть "yes"
- Невстроенные шрифты: сообщите названия шрифтов; предложите добавить встраивание шрифтов в опции компиляции

**3e. Проверка полноты содержимого**:
- Поиск маркеров `TODO`, `FIXME`, `XXX`
- Поиск `\missingfigure`, пустых разделов (`\section{X}` без содержимого)
- Поиск неиспользуемых фигур/таблиц (`\includegraphics` присутствует, но нет `\ref`)
- Проверка наличия аннотации и её непустоты

```markdown
## Чеклист подачи

- [ ] Количество страниц в пределах лимита площадки ({L} страниц)
```


## Ограничения

- **Не изменяйте содержимое wiki**:操作айте только над директорией paper/ и wiki/log.md
- **Автоисправление требует --fix**: по умолчанию только отчёт об ошибках; не исправляйте
- **[UNCONFIRMED] — жёсткий блокатор**: [UNCONFIRMED] в чеклисте подачи = невозможна подача
- **Максимум 3 раунда исправление-компиляция**: предотвращение бесконечных циклов исправлений
- **Не удаляйте пользовательское содержимое**: автоисправление только добавляет или исправляет; не удаляете рукописное содержимое
- **Зависимость от pdfinfo/pdffonts**: если не установлены, пропустите соответствующую проверку и аннотируйте "инструмент недоступен"
- **Проверка анонимности является эвристической**: может давать ложные срабатывания; аннотируйте как ПРЕДУПРЕЖДЕНИЕ, а не НЕ ПРОЙДЕНО

## Обработка ошибок

- **main.tex не найден**: ошибка; предложите сначала запустить /paper-draft
- **latexmk не установлен**: ошибка; предоставьте команду установки (`sudo apt install texlive-full` или `brew install --cask mactex`)
- **Компиляция не удалась и автоисправление безуспешно**: вывод полного лога ошибок + локализация конкретного .tex файла и номера строки
- **pdfinfo/pdffonts не установлены**: пропустите проверки страниц/шрифтов; аннотируйте в отчёте
- **PAPER_PLAN не найден**: пропустите извлечение информации о площадке; используйте лимит по умолчанию (10 страниц); предупредите пользователя
- **Проблема прав доступа** (tlmgr требует sudo): сообщите список пакетов, требующих ручной установки
