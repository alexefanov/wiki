# /research

> Конвейер исследований от начала до конца, который собирает все навыки в полный рабочий процесс исследований.
> Этап 0 (Bootstrap) + 5 Этапов + 2 Контрольные точки человека, охватывающие полный пайплайн от пустой wiki до подачи статьи.
> **Вход без трения**: если wiki пуста, Bootstrap запускается автоматически (поиск + авто-загрузка 5 статей); нет необходимости запускать /init вручную.
> Каждая контрольная точка и этап сохраняют прогресс в `wiki/outputs/pipeline-progress.md`, поддерживая восстановление между сессиями.
>
> **Этап 3 неблокирующий**: эксперименты развиваются и управление возвращается немедленно (режим `--auto` автоматически настраивает CronCreate для мониторинга каждые 30 минут).
> Когда все эксперименты завершаются, Этап 4 запускается автоматически. Используйте `/exp-status` в любое время для проверки прогресса.
>
> Режим `--auto` пропускает ручное подтверждение (автоматически выбирает топ-1 идею). `--skip-paper` запускает исследования без написания статьи.

## Входы

- `direction`: описание направления исследований или путь к файлу `RESEARCH_BRIEF.md`
- `--auto` (опционально): полностью автоматический режим
- `--start-from <stage>` (опционально): возобновление выполнения с указанного этапа
- `--skip-paper` (опционально): только исследования (этапы 1-4), без написания статьи (этап 5)
- `--venue` (опционально): целевая конференция, передаётся в /paper-plan

## Выходы

- **Обновления wiki** (делегируются поднавыкам): ideas/, experiments/, methods/, outputs/, graph/
- **wiki/outputs/pipeline-progress.md** — снимок прогресса пайплайна (для восстановления)
- **wiki/outputs/PIPELINE_REPORT.md** — полный отчёт пайплайна
- **Директория paper/** (если не --skip-paper) — подаваемая статья
- **wiki/log.md** — журнал, добавляемый после каждого этапа

## Взаимодействие с Wiki

### Чтение
- `wiki/graph/context_brief.md` — глобальный контекст (передаётся поднавыкам)
- `wiki/graph/open_questions.md` — пробелы в знаниях (передаётся в /ideate)
- `wiki/ideas/*.md` — Контрольная точка 1, Вердикт Этапа 4, План статьи Этапа 5
- `wiki/experiments/*.md` — проверки статуса Этапа 3-4
- `wiki/methods/*.md` — контекст написания статьи Этапа 5
- `wiki/outputs/pipeline-progress.md` — восстановление состояния --start-from

### Запись
- `wiki/outputs/pipeline-progress.md` — сохранение прогресса на каждой контрольной точке
- `wiki/outputs/PIPELINE_REPORT.md` — финальный отчёт
- `wiki/log.md` — добавление записей в журнал
- Все другие записи в wiki делегируются поднавыкам

### Создаваемые графовые рёбра
- Нет напрямую — все графовые рёбра делегируются поднавыкам

## Рабочий процесс

**Предусловие**:
1. Убедитесь, что рабочая директория — корень проекта wiki
2. Если указан `--start-from`, прочитайте `wiki/outputs/pipeline-progress.md` для восстановления состояния

### Шаг 0: Инициализация

1. **Парсинг входа**
2. **Обнаружение авто-восстановления** (когда --start-from не указан)
3. **Проверка восстановления** (когда --start-from указан)
4. **Создание файла прогресса** `wiki/outputs/pipeline-progress.md`
5. **Добавление в журнал**
6. **Снимок состояния wiki**

### Этап 0: Bootstrap (автоматически при пустой wiki)

**Условие запуска**: `level == "cold"` и `papers < 3`

1. Инициализация структуры wiki
2. Поиск релевантных статей (DeepXiv + Semantic Scholar + arXiv)
3. Объединение, ранжирование и выбор топ-5
4. Авто-загрузка каждой статьи через `/ingest`
5. Пересборка производных данных
6. Отчёт bootstrap
7. Журнал + обновление прогресса

### Этап 1: Обнаружение идей

Вызов `/ideate`:
```
Skill: ideate
Args: "{direction}" --auto
```

### Контрольная точка 1: Выбор идеи

- Режим `--auto`: автоматический выбор топ-1
- Интерактивный режим: перечисление идей, запрос выбора у пользователя

### Этап 2: Проектирование экспериментов

Вызов `/exp-design`:
```
Skill: exp-design
Args: "{idea_slug}"
```

### Этап 3: Выполнение экспериментов (неблокирующий)

#### Этап 3a: Развёртывание всех

Запуск каждого эксперимента через `/exp-run {experiment_slug}`

#### Этап 3b: Ожидание (неблокирующий)

Расчёт ETA, сохранение прогресса, завершение текущей сессии

#### Этап 3c: Сбор (после завершения экспериментов)

Вызов `/exp-run {experiment_slug} --collect` для каждого развёрнутого эксперимента

### Этап 4: Вердикт и итерация

Вызов `/exp-eval` для каждого завершённого эксперимента

Оценка достаточности связанной идеи:
- Достаточно → Контрольная точка 2
- Недостаточно → итерация (максимум 2)

### Контрольная точка 2: Подтверждение готовности статьи

### Этап 5: Написание статьи

Последовательный вызов: /paper-plan → /paper-draft → /refine → /paper-compile

### Финальный шаг: Отчёт пайплайна

Генерация `wiki/outputs/PIPELINE_REPORT.md`

## Ограничения

- **Оркестратор не изменяет напрямую сущности wiki**
- **Контрольные точки и этапы должны сохранять прогресс**
- **Этапы 3a не прерываются при ошибках развёртывания**
- **Ошибка сбора базового метода завершает пайплайн**
- **Этап 3b завершает сессию**
- **Максимум 2 итерации**
- **--auto не пропускает вычисления**
- **--skip-paper всё равно запускает Этап 4 /exp-eval**
- **Лог каждого этапа**

## Обработка ошибок

- **pipeline-progress отсутствует, но указан --start-from**
- **pipeline-progress повреждён**
- **Ошибка вызова поднавыка**
- **Все генерации идей завершились ошибкой**
- **Все развёртывания экспериментов завершились ошибкой**
- **Этап 3c сбор базового метода завершился ошибкой**
- **Пользователь выбрал остановку**
- **RESEARCH_BRIEF.md сформирован неправильно**
- **Wiki пуста** → авто-триггер Этапа 0 Bootstrap
- **Доказательства идей всё ещё недостаточны после итерации**
